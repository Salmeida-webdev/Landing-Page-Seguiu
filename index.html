Perguntas frequentes

O que você precisa saber.

Este site apresenta um conceito visual e funcional para portfólio.

O Seguiu já é um produto disponível?

Não. Seguiu é um conceito de SaaS criado para demonstrar uma landing page e uma interface de produto em um projeto de portfólio.

Os dados do painel são reais?

Não. Nomes, valores, quantidades e etapas são fictícios e foram incluídos apenas para demonstrar a interface.

Como o conceito organiza as negociações?

A proposta é reunir contatos, etapas, propostas e próximos retornos em uma visão comercial centralizada.

Posso pedir uma solução parecida para minha empresa?

Sim. O botão abre uma conversa no WhatsApp com Segundo para falar sobre um projeto digital semelhante.
