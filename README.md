# Seguiu — landing page conceito

Landing page estática de portfólio para um conceito de SaaS B2B de acompanhamento comercial.

## Rodar localmente

Abra `index.html` no navegador ou, com Python instalado, execute na pasta do projeto:

```powershell
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Estrutura

- `index.html`: conteúdo e painel demonstrativo.
- `styles.css`: identidade visual e layout responsivo.
- `script.js`: menu mobile e eventos condicionais para dataLayer.
- `netlify.toml`: configuração de publicação estática.

O painel usa dados fictícios identificados na página. O CTA abre o WhatsApp de contato com uma mensagem sobre projetos semelhantes. Seguiu é um nome conceitual e ainda não passou por busca formal de disponibilidade de marca ou domínio.
